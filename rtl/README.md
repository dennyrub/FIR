# Parameterized N-Tap FIR Filter (Configured for 8 Taps)

Проект по разработке цифрового КИХ-фильтра (FIR) на SystemVerilog. 
Проект демонстрирует полный цикл RTL-разработки: от математической модели на Python до побитовой верификации и подготовки к синтезу.

## Ключевые особенности
*   **Архитектура:** Прямая форма (Direct Form). 
*   **Масштабируемость:** Параметризованная архитектура (`NTAPS`). Текущая конфигурация — 8 отводов, но фильтр легко расширяется до 16, 32 и более без изменения RTL-кода.
*   **Арифметика:** Фиксированная точка Q1.15 (16-битные отсчеты и коэффициенты).
*   **Аккумулятор:** 35 бит (с запасом на переполнение).
*   **Округление и насыщение:** Округление к ближайшему `(acc + 2^14) >> 15` и аппаратное насыщение (saturation) в диапазон -32768...32767.
*   **Латентность:** 2 такта (регистр окна + регистр выхода).
*   **Верификация:** Сквозная (End-to-End). RTL побитово совпадает с эталонной моделью на Python, включая крайние случаи переполнения.

## Инструменты и окружение
*   **RTL:** SystemVerilog
*   **Моделирование:** Verilator 5.020 (Linux/WSL) + C++ обертка.
*   **Эталонная модель:** Python 3.
*   **Сборка:** Makefile.
*   **Контроль версий:** Git.
